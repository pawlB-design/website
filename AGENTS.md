# Project workflow

Keep this a lightweight Zola site. Read README.md for build commands.
For Patreon discovery/imports, read docs/patreon-sync.md and the inventory first.
Preserve post IDs, slugs, source timestamps, decisions and hash safeguards.
Do not copy TLF's content, campaign ID, editorial decisions or brand assets.
New posts default to review. Never bypass Patreon access restrictions.
Preserve unrelated local changes. Deployment is separate from local builds.
